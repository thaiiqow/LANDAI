# Ландай — портал проектируемого города
Чистые HTML/CSS/Vanilla JS. Откройте `index.html` или опубликуйте на GitHub Pages (Settings → Pages → ветка main, корень).
- Каждый раздел — отдельный файл в `pages/`; общий код в `js/main.js`, раздел определяется по `data-page` у `<body>`.
- `js/translations.js` — тексты RU/EN и список разделов; `js/data.js` — алфавит, тоны, автобусы, маршруты, новости, галерея, контакты.
- Ландайский: вписывайте переводы прямо в `js/landai.js` (ключ → перевод). Или переключите язык, нажмите ✎ и кликайте по тексту, затем ⇪ выгрузит готовый `landai.js` для замены файла в проекте.
- Фото: положите в `images/` и добавьте пути в `gallery` (data.js).
- Все проектируемые объекты помечены как проектируемые; неизвестные данные — «—».
